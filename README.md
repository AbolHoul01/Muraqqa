## 📖 About Muraqqa
In Persian artistic heritage, a **Muraqqa (مرقع)** represents a curated album of calligraphy and miniature artworks. 
**Muraqqa** brings this spirit into the modern web: a free, open-source platform allowing anyone to craft beautiful, privacy-first resumes with ease.

---

## ✨ Key Features (WIP)

- 🔓 **100% Free & Open-Source:** No hidden paywalls or premium restrictions.
- 🔒 **End-to-End Privacy:** Zero-knowledge data architecture. Your data stays yours.
- ⚡ **Real-Time Live Preview:** Powered by Next.js and Zustand for instant editing.
- 🎨 **Modular Template API:** Designed for developers to easily write and contribute customized templates.
- 🐳 **Docker-First:** One command (`docker compose up`) to host locally or on server.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), TypeScript, Zustand, Tailwind CSS
- **Backend:** Golang (Fiber / Clean Architecture)
- **Database:** PostgreSQL (`JSONB`)
- **DevOps:** Docker, Docker Compose
