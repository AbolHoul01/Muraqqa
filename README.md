# Muraqqa
Muraqqa: A modern, free, open-source, and privacy-first resume builder with modular template architecture. Built with Next.js, Golang, PostgreSQL, and Docker / مرقع (Muraqqa): یک رزومه‌ساز مدرن، رایگان، اوپن‌سورس و حفظ‌کننده حریم خصوصی با معماری ماژولار. توسعه‌یافته با Next.js، Golang، PostgreSQL و Docker.
