# 🐳 زیرساخت و کانتینرسازی داکر (Docker & Orchestration)

> **دسته‌بندی:** زیرساخت و دوآپس  
> **فایل‌های مرجع:** `docker-compose.yml`، `apps/api/Dockerfile` و `apps/web/Dockerfile`

---

## 🌟 ویژگی اصلی (Main Feature): استقرار تک‌دستوری (One-Command Deployment)

پروژه مرقع با فلسفه **Docker-First** ساخته شده است. این رویکرد به هر توسعه‌دهنده یا کاربر اجازه می‌دهد کل مجموعه فرانت‌اند، هسته بک‌اند و پایگاه داده را با اجرای یک دستور ساده بر روی سیستم محلی یا سرور اختصاصی خود (Self-Hosting) راه‌اندازی کند:

```bash
docker compose up --build
```

## 🧩 ریزویژگی‌ها (Sub Features)

### ۱. کانتینر پایگاه داده (`db` - PostgreSQL 16)
* **ایمیج پایه:** `postgres:16-alpine` (حجم بسیار سبک و امن)
* **پورت اکسپوز:** `5432:5432`
* **ماندگاری داده‌ها:** استفاده از والیوم اختصاصی داکر به نام `postgres_data` که مانع از بین رفتن اطلاعات با ری‌استارت شدن کانتینر می‌شود.
* **بررسی سلامت (Healthcheck):**
  * اجرای مداوم فرمان `pg_isready -U muraqqa_admin -d muraqqa_db` در فواصل ۵ ثانیه‌ای.
  * تضمین در دسترس بودن قطعی پایگاه داده قبل از شروع به کار بک‌اند Go.

### ۲. کانتینر هسته API (`api` - Go Backend)
* **پورت اکسپوز:** `8080:8080`
* **استراتژی ساخت (Multi-Stage Build):**
  * استیج ۱ (Builder): کامپایل کد منبع با ایمیج `golang:1.23-alpine` با فلگ‌های بهینه‌سازی `CGO_ENABLED=0` برای ایجاد فایل باینری کاملاً استاتیک.
  * استیج ۲ (Runner): ایمیج نهایی بر پایه `alpine:3.20` با حداقل حجم (کمتر از ۲۰ مگابایت) همراه با پکیج گواهی‌نامه‌های امنیتی `ca-certificates`.
* **وابستگی به سرویس‌ها:** اتصال مشروط به سلامت دیتابیس (`condition: service_healthy`).

### ۳. کانتینر وب و فرانت‌اند (`web` - Next.js)
* **پورت اکسپوز:** `3000:3000`
* **استراتژی ساخت:**
  * اجرای فرآیند کامپایل و بیلد کلاینت با `npm run build`
  * ایمیج نهایی سبک `node:20-alpine`
  * ران کردن سرور پروداکشن Next.js با `npm run start`
