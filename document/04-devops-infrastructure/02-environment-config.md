# ⚙️ متغیرهای محیطی و سلامت سرویس‌ها (Config & Healthcheck)

> **دسته‌بندی:** زیرساخت و پیکربندی  
> **فایل‌های مرجع:** `docker-compose.yml` و `apps/api/cmd/api/main.go`

---

## 🌟 ویژگی اصلی (Main Feature): مدیریت متمرکز پیکربندی و نظارت بر سلامت

پروژه از اصول متدولوژی استاندارد دوازده‌عاملی (12-Factor App) برای پیکربندی از طریق متغیرهای محیطی پیروی می‌کند.

---

## 📋 متغیرهای محیطی (Environment Variables)

### ۱. سرویس هسته بک‌اند (`apps/api`)

| نام متغیر | نوع | مقدار پیش‌فرض | توضیحات |
| :--- | :---: | :--- | :--- |
| `PORT` | رشته عددی | `8080` | پورت گوش دادن به درخواست‌های HTTP سرور |
| `DB_HOST` | رشته | `localhost` (در داکر: `db`) | آدرس میزبان سرویس دیتابیس PostgreSQL |
| `DB_PORT` | رشته عددی | `5432` | پورت اتصال به پایگاه داده |
| `DB_USER` | رشته | `muraqqa_admin` | نام کاربری دیتابیس |
| `DB_PASSWORD` | رشته | `secretpassword` | کلمه عبور دیتابیس |
| `DB_NAME` | رشته | `muraqqa_db` | نام دیتابیس اختصاصی مرقع |
| `JWT_SECRET` | رشته | `muraqqa_super_secret_jwt_signing_key_2026` | کلید مخفی امضای توکن‌های احراز هویت |

### ۲. سرویس فرانت‌اند (`apps/web`)

| نام متغیر | نوع | مقدار پیش‌فرض | توضیحات |
| :--- | :---: | :--- | :--- |
| `NEXT_PUBLIC_API_URL` | URL | `http://localhost:8080` | آدرس پایه بک‌اند جهت فراخوانی درخواست‌ها از مرورگر کاربر |

## 🩺 اندپوینت‌های پایش سلامت (Healthcheck Endpoints)

### پایش زنده بک‌اند (API Health Ping)
* **روت:** `GET /health`
* **دسترسی:** عمومی بدون نیاز به توکن
* **خروجی نمونه:**
```json
{
  "service": "Muraqqa Core API",
  "status": "ok"
}
```

این اندپوینت برای لودبالانسرها، مانیتورینگ آپ‌تایم و کانتینر ارکستریتورها طراحی شده تا در صورت بروز هرگونه مشکل یا قطعی شبکه بلافاصله وضعیت شناسایی گردد.
