# 🧠 موتور وضعیت و بوم زنده (Core Canvas & State Engine)

> **دسته‌بندی:** بخش فرانت‌اند (`apps/web`)  
> **مسیر سورس‌کد:** `apps/web/src/store/useResumeStore.ts` و `apps/web/src/components/builder/PreviewCanvas.tsx`

---

## 🌟 ویژگی اصلی (Main Feature): موتور متمرکز مدیریت وضعیت فرانت‌اند

هسته مرکزی فرانت‌اند مرقع با استفاده از **Zustand v5** پیاده‌سازی شده است. این سیستم به گونه‌ای طراحی شده که ویرایش‌های کاربر بدون ایجاد بار پردازشی اضافه و با استفاده از الگوی **Atomic Selectors** مستقیماً به بوم پیش‌نمایش متصل می‌شوند و تجربه کاربری بدون هیچ‌گونه لگ و تأخیر (Zero-Lag Typing) را رقم می‌زنند.

---

## 🧩 ریزویژگی‌ها (Sub Features)

### ۱. معماری تک‌منبعی داده‌ها (Single Source of Truth)
تمام بخش‌های رزومه شامل اطلاعات تماس، سوابق شغلی، سوابق تحصیلی، مهارت‌ها و تنظیمات ظاهری در یک استیت یکپارچه و به صورت تایپ‌شده با TypeScript نگهداری می‌شوند.

* **مدل تایپ اصلی:** اینترفیس `ResumeData` در فایل `apps/web/src/types/resume.ts`:
```typescript
export interface ResumeData {
  personalInfo: PersonalInfo;
  workExperience: WorkExperience[];
  education: Education[];
  skills: Skill[];
  themeSettings: ThemeSettings;
}
```

### ۲. پایداری داده‌ها در حافظه مرورگر (LocalStorage Persistence)
برای جلوگیری از پریدن داده‌های کاربر بر اثر رفرش ناخواسته صفحه یا بستن تب، استیت با استفاده از میان‌افزار `persist` در کلید `muraqqa-resume-store` مرورگر کلاینت ذخیره می‌گردد.
* **کد پیاده‌سازی:**
```typescript
persist(
  (set) => ({ ... }),
  {
    name: "muraqqa-resume-store",
    skipHydration: false,
  }
)
```

### ۳. سیستم تاریخچه و بازگردانی هوشمند (Temporal Undo / Redo)
با تلفیق میان‌افزار `temporal` از کتابخانه `zundo`، هر تغییری که در آبجکت `resume` صورت می‌پذیرد در پشته تاریخچه (Time-travel Stack) ثبت می‌شود.
* **ویژگی‌های این قابلیت:**
  * دکمه بازگردانی (Undo): بازگشت به مقدار ثانیه‌های قبل با کلیک کاربر
  * دکمه تکرار (Redo): بازیابی وضعیت قبلی در صورت بازگشت
  * غیرفعال شدن داینامیک دکمه‌ها در صورت خالی بودن پشته (`pastStates.length === 0` یا `futureStates.length === 0`)
  * پارتشین‌بندی دقیق فقط روی فیلد `resume` تا متغیرهای فرعی پشته را آلوده نکنند.

### ۴. پاک‌سازی و بازنشانی سریع (Reset State)
اکشن `resetResume` امکان بازگرداندن کل رزومه به مقادیر پیش‌فرض ساختاریافته (Initial State) را با اخذ تاییدیه از کاربر فراهم می‌کند.

### ۵. بوم نمایش استاندارد برگه کاغذ A4 (`PreviewCanvas`)
کامپوننت `PreviewCanvas` یک فریم با مشخصات فیزیکی استاندارد کاغذ پرینت رندر می‌کند:
* عرض ثابت: `w-[210mm]`
* حداقل ارتفاع استاندارد: `min-h-[297mm]`
* استایل پس‌زمینه کاغذی و طبیعی (`bg-muraqqa-paper`)
* تطبیق آنی جهت نوشتار بر اساس وضعیت فعلی تم (`dir={themeSettings.direction}`)

## 📊 مقایسه عملکردی (Performance Benefits)

| شاخص | رویکرد معمولی React State | معماری Zustand در مرقع |
| :--- | :--- | :--- |
| **دفعات رندر صفحه** | با هر کلید تایپ، کل فرم و پیش‌نمایش رندر می‌شود | فقط کامپوننت مرتبط و نود متن روی بوم تغییر می‌کند |
| **نگهداری هنگام رفرش** | داده‌ها از دست می‌روند | به شکل آنی از LocalStorage بازیابی می‌شوند |
| **امکان تصحیح اشتباه** | وجود ندارد مگر با کدنویسی پیچیده | با کلیک روی Undo فورا به حالت قبل بازمی‌گردد |
