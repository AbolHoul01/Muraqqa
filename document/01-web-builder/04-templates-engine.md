# 📐 موتور قالب‌های ماژولار (Modular Template Engine)

> **دسته‌بندی:** بخش فرانت‌اند (`apps/web`)  
> **مسیر سورس‌کد:** `apps/web/src/templates/...`

---

## 🌟 ویژگی اصلی (Main Feature): معماری ماژولار و توسعه‌پذیر قالب‌ها (Plug & Play Templates)

یکی از ارکان پروژه مرقع، فراهم ساختن بستری آسان برای جامعه توسعه‌دهندگان متن‌باز است تا بتوانند بدون نیاز به تغییر منطق اصلی یا دستکاری بوم، تنها با نوشتن یک کامپوننت React، قالب جدیدی به سیستم اضافه کنند.

---

## 🧩 ریزویژگی‌ها (Sub Features)

### ۱. معماری رجیستری پویا (Dynamic Template Registry)
در فایل `apps/web/src/templates/registry.ts` قالب‌ها با استفاده از `next/dynamic` ایمپورت می‌شوند. این معماری تضمین می‌کند که کدهای مربوط به قالب فقط در صورت نیاز لود شوند (Code Splitting و Lazy Loading) که حجم باندل اولیه صفحه را به حداقل می‌رساند:

```typescript
export const TemplateRegistry: Record<string, ComponentType<TemplateProps>> = {
  classic: dynamic(() => import("./ClassicTemplate")),
  modern: dynamic(() => import("./ModernTemplate")),
};

export const getTemplate = (id: string): ComponentType<TemplateProps> => {
  return TemplateRegistry[id] || TemplateRegistry["classic"];
};
```

### ۲. قالب شماره ۱: مدرن (`ModernTemplate`)
این قالب برای متخصصان حوزه تکنولوژی، طراحی و استارتاپ‌ها بهینه‌سازی شده است:
* **هدر شاخص رنگی:** یک بلاک رنگی پررنگ در بالای صفحه با پس‌زمینه `themeSettings.primaryColor` که نام، عنوان شغلی و لینک‌های تماس را به صورت شفاف و کنتراست‌بالا نمایش می‌دهد.
* **کارت خلاصه حرفه‌ای:** باکس استایل‌دهی‌شده با رنگ پس‌زمینه خاکستری روشن و خط حاشیه برجسته در ابتدای سطر.
* **تایم‌لاین با خطوط حاشیه‌ای (Border-Start):** سوابق شغلی و تحصیلی با خطوط باریک با کد رنگی نیمه‌شفاف آیکونیک در کنار تاریخ و شرکت تفکیک می‌شوند.
* **چیپ‌ها و نشانگرهای مهارت:** نمایش مهارت‌ها در قالب تگ‌های گرد و رنگی متناسب با تم رزومه.

### ۳. قالب شماره ۲: کلاسیک (`ClassicTemplate`)
این قالب برای محیط‌های سنتی‌تر، دانشگاهی، حقوقی و سیستم‌های سنتی سازمانی مناسب است:
* **هدر با خط جداکننده زیرین:** نام متقاضی با فونت بزرگ با رنگ تم و خط جداکننده افقی ظریف.
* **چیدمان ستونی و متنی تمیز:** حذف پس‌زمینه‌های تیره جهت کاهش مصرف جوهر در چاپ‌های سنتی.
* **عناوین بخش‌ها با بردر افقی:** عناوین سوابق شغلی و تحصیلی با بردر باریک افقی از سایر متون متمایز می‌شوند.
* **نمایش لیستی مهارت‌ها:** نمایش دسته‌بندی‌شده مهارت‌ها و کلمات کلیدی همراه با میزان تسلط.

### ۴. مدیریت هوشمند شکست صفحه (Page Break Isolation)
تمام بخش‌های قالب‌ها با کلاس استاندارد `page-break-avoid` مجهز شده‌اند:
* جلوگیری از نصف شدن کارت سابقه شغلی در مرز دو صفحه A4.
* حفظ یکپارچگی بلاک‌های تحصیلی و مهارت‌ها هنگام صدور PDF.

## 🛠️ نحوه مشارکت و افزودن قالب جدید (Developer Guide)

هر توسعه‌دهنده تنها با طی دو مرحله زیر می‌تواند قالبی جدید به مرقع اهدا کند:

۱. ایجاد یک فایل کامپوننت جدید در مسیر `apps/web/src/templates/MinimalTemplate.tsx`:
```tsx
import React from "react";
import { TemplateProps } from "./types";

export const MinimalTemplate: React.FC<TemplateProps> = ({ data }) => {
  return <div>{/* ساختار تم تمیز و دلخواه */}</div>;
};
export default MinimalTemplate;
```

۲. افزودن نام قالب به `TemplateRegistry` در `apps/web/src/templates/registry.ts`.
