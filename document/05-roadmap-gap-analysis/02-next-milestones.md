## 🚀 نقشه راه فازبندی‌شده (Roadmap Phases)

### 🔹 فاز ۱: یکپارچه‌سازی فرانت‌اند و بک‌اند (Integration Phase) - اولویت بالا 🔴
- [ ] ساخت سرویس API Client تایپ‌شده در `apps/web/src/services/api.ts` با استفاده از `fetch` بومی.
- [ ] ساخت مدال / صفحه لاگین و ثبت‌نام در فرانت‌اند (Login & Register Modal).
- [ ] ذخیره امن توکن JWT در کلاینت (HTTP-only Cookie یا Memory/LocalStorage).
- [ ] پیاده‌سازی تولید کلید ۳۲ بایتی در مرورگر کاربر با استفاده از `window.crypto.subtle` (Zero-Knowledge Key Vault).
- [ ] افزودن دکمه‌های «ذخیره در ابر» (Cloud Sync) و «لیست رزومه‌های من» در هدر رزومه‌ساز.

### 🔹 فاز ۲: بهبود تجربه کاربری و صفحه فرود (Landing & UX Polish) - اولویت متوسط 🟡
- [ ] بازنویسی صفحه اصلی (`apps/web/src/app/page.tsx`) و تبدیل آن به صفحه لندینگ شکیل با معرفی هویت هنری مرقع.
- [ ] افزودن کلیدهای میانبر صفحه‌کلید (Shortcuts نظیر `Ctrl+Z` برای Undo و `Ctrl+Y` برای Redo).
- [ ] اضافه کردن قابلیت پیش‌نمایش تمام‌صفحه (Full-Screen Preview Mode).
- [ ] تست و تثبیت واکنش‌گرایی در نمایشگرهای موبایل و تبلت.

### 🔹 فاز ۳: گسترش اکوسیستم قالب‌ها (Template Ecosystem) - اولویت متوسط 🟡
- [ ] پیاده‌سازی قالب مینیمال متمرکز بر ATS (`MinimalTemplate` / `ATSOptimizedTemplate`).
- [ ] پیاده‌سازی قالب خلاقانه دو ستونه (`CreativeSidebarTemplate`).
- [ ] افزودن قابلیت انتخاب و آپلود تصویر پروفایل کاربر به صورت Base64 در فیلد اختیاری `photo`.

### 🔹 فاز ۴: سرویس صدور اختصاصی PDF سروری (Server-Side Rendering PDF) - اولویت آتی 🟢
- [ ] افزودن یک ورکر سبک مبتنی بر Chromium Headless / Puppeteer برای ایجاد PDF پیکسلی دقیق در سرور به عنوان گزینه جایگزین پرینت مرورگر.
- [ ] ایجاد اندپوینت دریافت PDF مستقیم با لینک امن و اشتراک‌گذاری موقت.
