# Muraqqa Agent Guidelines

## UI & Theme
Brand tokens only (`muraqqa-navy`, `muraqqa-teal`, `muraqqa-paper`, `muraqqa-slate`). Zero raw hex. Logical properties only (`ms-`, `me-`, `ps-`, `pe-`, `text-start`). No dark mode. No new dependencies. Server Components by default. Text on `bg-muraqqa-teal` is always `text-muraqqa-navy`. See `.claude/skills/muraqqa-theme/SKILL.md` for full recipes and guidelines.
